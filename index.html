Лабораторная работа №1

«Сравнение количеств теплоты при смешивании воды разной температуры»

Физика, 8 класс — рабочий лист учащегося

Цель работы

Сравнить количество теплоты, отданное горячей водой, с количеством теплоты, полученным холодной водой при теплопередаче.

Приборы и материалы

Калориметр, мензурка из термостойкого стекла, термометр, сосуд для горячей воды, чайник с горячей водой, сосуд с холодной водой.

Расчётные формулы

  • Q = c·m·|t − t₀| — количество теплоты
  • Q₁ = Q₂ — условие теплового баланса (закон сохранения энергии)
  • ΔQ = Q₂ − Q₁ — абсолютная разность количеств теплоты
  • ε = (ΔQ / Q₂)·100% — относительная погрешность
  • c = 4200 Дж/(кг·°C) — удельная теплоёмкость воды

Как оформить решение (по данным столбца «Образец»)
Дано: m₁ = 0,20 кг, t₁ = 15 °C, m₂ = 0,15 кг, t₂ = 80 °C, t = 40 °C, c = 4200 Дж/(кг·°C) Q₁ = c·m₁·(t − t₁) = 4200 · 0,20 · (40 − 15) = 4200 · 0,20 · 25 = 21000 Дж Q₂ = c·m₂·(t₂ − t) = 4200 · 0,15 · (80 − 40) = 4200 · 0,15 · 40 = 25200 Дж ΔQ = Q₂ − Q₁ = 25200 − 21000 = 4200 Дж ε = (ΔQ / Q₂) · 100% = (4200 / 25200) · 100% ≈ 16,7%
